# Video Game Backlog Tracker
Created by Colin Lee

## Project Description

The Video Game Backlog Tracker is a program that allows users to organize their video game collection. Uses can add games, view their collection, search for specific games, mark games as completed, and rate their games. The program also provides statistics about the collection.

## Features

1. Add a game with its title, genre, and status.
2. View all games in the collection.
3. Search for a game by its title.
4. Mark a game as completed.
5. Rate a game from 1 to 10.
6. View statistics showing total, completed, and remaining games.
7. Exit the program.

## How to Run

1. Open the repository in GitHub Codespaces or another environment with Python installed.
2. Open the terminal.
3. Run the following command

     python project1.py

4. Follow the menu instructions to use the program.

## Python Concepts Used

- Variables and data types
- Lists and dictionaries
- If, elif, and else statements
- For loops and while loops
- User input
- String methods and conditional comparisons

## Limitations

Games are stored temporarily while the program is running. Closing the program resets the collection.
